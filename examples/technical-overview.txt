# Knowledge Agent Demo 技术介绍

## 一、项目定位
Knowledge Agent Demo 是一个基于 Java 17 和 Spring Boot 3 构建的企业知识库 Agent 示例。它不只是一个普通聊天机器人，而是一个带有知识检索、上下文记忆、工具调用和模型接入能力的可扩展原型。

## 二、整体架构
项目采用“控制器 + 应用服务 + 编排层 + 能力模块 + 存储层”的结构。
主要模块包括：
- `chat`：处理聊天请求和会话历史查询
- `docs`：处理知识文档上传与列表查询
- `rag`：负责文档切片、向量生成和知识检索
- `memory`：负责短期记忆和长期记忆
- `tool`：负责工具匹配与工具执行
- `llm`：负责模型调用与 fallback 策略
- `shared.store`：负责内存存储与 JDBC 存储抽象
- `config`：负责配置项和运行模式切换

## 三、核心能力
系统通过 `/api/chat` 接收用户消息，结合最近上下文、知识命中、长期记忆和工具执行结果生成回答。系统也支持通过 `/api/docs/upload` 上传知识文档，并基于向量和关键词进行检索。

## 四、当前局限
当前版本仍偏 Demo：
- Embedding 仍使用简化实现
- 工具调用虽然已可演示，但还需要更完整的异常治理
- 远程模型调用缺少更完善的超时、重试和观测能力

## 五、后续方向
后续可以优先补强真实 Embedding 服务接入、`pgvector` 检索、工具调用可观测性，以及更完善的权限控制。
